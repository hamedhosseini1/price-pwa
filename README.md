# قیمت لحظه‌ای — PWA فارسی (ارز، طلا و سکه، کریپتو، نفت)

وب‌اپلیکیشن فارسی و راست‌چین برای نمایش **قیمت لحظه‌ای** ارزها، طلا و سکه،
ارزهای دیجیتال و نفت؛ با میانگین‌گیری از چند منبع، مولتی‌کارنسی (تومان/دلار)،
مبدل، مقایسه نموداری، علاقه‌مندی‌ها، هشدار قیمت و پشتیبانی آفلاین (PWA).

## شروع سریع

```bash
cd price-pwa
cp .env.example .env        # و کلید BrsApi را در آن بگذارید (اختیاری ولی توصیه‌شده)
npm install
npm run dev                 # http://localhost:3000
```

دریافت کلید رایگان BrsApi (۱۵۰۰ درخواست/روز):
https://brsapi.ir/tsetmc-exchange-free-bourse-api-key-request/

> بدون کلید هم اپ کار می‌کند (tgju + کوین‌گکو + ECB) ولی پوشش کامل
> (نفت، پلاتین/پالادیوم، دقت بیشتر) نیازمند کلید است.

## متغیرهای محیطی (`.env`)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BRSAPI_KEY` | — | کلید رایگان BrsApi (منبع اصلی). سقف پلن رایگان **۱۵۰۰ درخواست/روز** |
| `BRSAPI_REFRESH_MS` | `150000` | رفرش BrsApi: هر ۲.۵ دقیقه → ≈۱۱۵۲ درخواست/روز (≈۷۷٪ سهمیه). روی 429 بک‌آف ۱۵ دقیقه‌ای خودکار |
| `TWELVEDATA_KEY` | — | اختیاری: کراس‌چک مستقل نفت (پلن رایگان ۸۰۰/روز؛ مصرف ما ≈۵۷۶/روز) |
| `TWELVEDATA_KEY` | — | اختیاری، برای کراس‌چک نفت (مستند، پیاده‌سازی آماده توسعه) |
| `ENABLE_BONBAST` | `0` | فقط با اجازه بونباست `1` کنید (ToS اسکرپینگ را ممنوع کرده) |
| `REFRESH_MS` | `45000` | فاصله رفرش منابع (حداقل ۱۰۰۰۰) |
| `OUTLIER_PCT` | `2.5` | آستانه حذف داده پرت (٪ انحراف از میانه) |

## معماری

```
app/
  page.tsx                 داشبورد (هیرو، علاقه‌مندی‌ها، تب‌ها، جدول/کارت)
  item/[slug]/page.tsx     جزئیات: نمودار ۲۴h/۷d/۱m، آمار، هشدار، جدول منابع
  converter/page.tsx       مبدل هر→هر + مقایسه چندنموداری نرمالایزشده
  api/prices/route.ts      اسنپ‌شات تجمیعی (کش + stale-while-revalidate)
  api/history/[slug]/      سری زمانی (سمپلر داخلی / آرشیو tgju / کوین‌گکو)
  api/health/route.ts      سلامت منابع
lib/
  catalog.ts               ~۶۵ آیتم + نگاشت نماد هر منبع
  aggregate.ts             نرمالایز → حذف پرت → میانگین وزنی
  store.ts                 کش اسنپ‌شات + سمپلر تاریخچه (data/history.json)
  sources/                 brsapi, tgju, coingecko, frankfurter, nobitex, bonbast
  format.ts / settings.tsx اعداد فارسی/انگلیسی + تنظیمات localStorage
components/                کارت، جدول مرتب‌شونده، نمودارهای SVG، هدر، استتوس‌بار
public/                    manifest، sw.js، آیکون‌ها
tests/                     ۲۱ تست fixture-محور
docs/SOURCES.md            جزئیات منابع و روش میانگین‌گیری
```

**استک:** Next.js 15 + TypeScript + CSS اختصاصی (بدون Tailwind برای کنترل کامل
RTL) + فونت وزیرمتن (CDN، با fallback) + نمودارهای SVG دست‌ساز (بدون وابستگی).
دیتابیس لازم نیست؛ تاریخچه روی دیسک (`data/history.json`) persist می‌شود.

## دیپلوی

### ورسل (پیشنهادی)
1. برو به **vercel.com** → با گیت‌هاب لاگین کن (Continue with GitHub)
2. **Add New → Project** → ریپوی **`hamedhosseini1/price-pwa`** را **Import** کن
3. در بخش **Environment Variables** این را اضافه کن (مقدارش را از فایل `.env` لوکال خودت کپی کن — هرگز کامیت نمی‌شود):
   - `BRSAPI_KEY` = کلید BrsApi (ضروری برای پوشش کامل: نفت، پلاتین، دقت بیشتر)
   - بقیه اختیاری‌اند و پیش‌فرض دارند (`REFRESH_MS=45000`، `BRSAPI_REFRESH_MS=150000`، `OUTLIER_PCT=2.5`)
4. **Deploy** را بزن. هر پوش به `main` گیت‌هاب = دیپلوی خودکار جدید.

نکات مهم ورسل:
- **پلن رایگان (Hobby)**: تایم‌اوت فانکشن ~۱۰ ثانیه است؛ کد طوری تنظیم شده که رفرش معمولاً ۲–۵ ثانیه طول بکشد. اولین بازدید بعد از مدت بیکاری ممکن است یکی‌دو رفرش طول بکشد (خودکار رetry می‌شود).
- **تاریخچه نمودار**: فایل‌سیستم سرورلس ماندگار نیست؛ سمپلر داخلی هر نمونه (instance) از نو شروع می‌شود ولی تاریخچه کریپتو (کوین‌گکو) و روزانه (آرشیو tgju) همیشه کار می‌کند.
- ریجن `fra1` (فرانکفورت) در `vercel.json` ست شده = کمترین تأخیر تا منابع ایرانی. (نکته فنی: داخل `vercel.json` کامنت نگذارید — JSON معتبر نیست و دیپلوی با خطای JSON می‌شکند.)

### سرور شخصی (VPS، Liara و…)

## تست


`BTC < $2M`) را چک می‌کند تا باگ واحد (ریال/تومان/دلار) فوراً لو برود.

## اکستنشن کروم

پوشه `extension/` یک اکستنشن MV3 است: پاپ‌آپ ۷ قیمت کلیدی (تومان/دلار)،
**بج لحظه‌ای قیمت دلار** روی آیکون تولبار (رفرش با `chrome.alarms`) و صفحه
تنظیمات (آدرس سرور، واحد، اعداد، فاصله رفرش بج).

نصب (حالت توسعه‌دهنده):
1. اپ را اجرا کنید (`npm run dev` روی پورت 3000)
2. در کروم بروید به `chrome://extensions` → حالت Developer را روشن کنید
3. «Load unpacked» → پوشه `price-pwa/extension` را انتخاب کنید
4. اگر اپ را دیپلوی کردید، آدرس را در Options اکستنشن بگذارید و دامنه را به
   `host_permissions` در `extension/manifest.json` اضافه کنید

تست خودکار: `node scripts/audit-extension.cjs` (کرومیوم واقعی؛ نیازمند سرور روی 3000).

## ربات تلگرام

ربات وب‌هوکی روی همین ورسل (بدون سرور جدا): قیمت سریع، جستجو، مبدل، منوی
دکمه‌ای دسته‌ها، واحد تومان/دلار هر چت و **هشدار قیمت** (کرون هر ۵ دقیقه،
one-shot: بعد از فعال‌شدن پاک می‌شود).

راه‌اندازی:
1. در تلگرام به **@BotFather** بگو `/newbot` → اسم + یوزرنیم → **توکن** را کپی کن
2. یک سکرت بساز: `openssl rand -hex 32`
3. در ورسل (Settings → Environment Variables) این‌ها را بگذار:
   `TELEGRAM_BOT_TOKEN`، `TELEGRAM_WEBHOOK_SECRET` (= همان سکرت)، `CRON_SECRET`
   (یک رشته تصادفی دیگر — ورسل خودش آن را در هدر کرون می‌فرستد)
4. لوکال اجرا کن:
   ```bash
   TELEGRAM_BOT_TOKEN=xxx TELEGRAM_WEBHOOK_SECRET=yyy npm run telegram-setup
   ```
   (وب‌هوک را روی `https://price-pwa.vercel.app/api/telegram` ست می‌کند)
5. دوباره دیپلوی کن تا envها اعمال شوند. بعد در تلگرام به ربات `/start` بده.

ذخیره‌سازی هشدارها: اگر `UPSTASH_REDIS_REST_URL/TOKEN` (Upstash Redis رایگان،
۲ دقیقه ساخت) را هم بگذاری، هشدارها ماندگار می‌شوند؛ وگرنه در حافظه‌اند
(لوکال اوکی، روی ورسل با cold start می‌پرند). دستورات کامل: داخل چت `/help`.
